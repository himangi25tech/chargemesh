# Estimate

One toy evening. Not a measured society, not a DISCOM tariff, not a carbon inventory.

Run `python3 sim/estimate.py`. The tables below match `sim/result.json` from that script. The filler is greedy: put the next slice of energy in the lowest slot that is still under the cap, then the cheaper slot. It is not the MPC in Van Kriekinge et al.

## Inputs

| Input | Value | Why it is here |
| --- | --- | --- |
| Cars | 20, all arrive 18:00, leave 07:00 | The pile-up in the notes |
| Battery energy each | 24 kWh | What the car still needs |
| Charger efficiency | 0.9 | Plug energy is 24 / 0.9 = 26.7 kWh |
| Max plug power | 7 kW | Uncontrolled, everyone takes this at once |
| Building | 100 kW, flat | Site load that does not move |
| Solar | 0 kW | 18:00. Nothing left to "save" |
| Site cap | 180 kW | Illustrative sanctioned load |
| Example price | ₹8 / ₹4 / ₹6 | 18:00–22:00 / 22:00–06:00 / 06:00–07:00. Not a real tariff |
| Example carbon | 0.72 / 0.45 / 0.55 kg per kWh | Same windows. Not a grid factor for India |

Slot size is 15 minutes. Horizon is 13 hours.

## Outputs

| Output | Uncontrolled | Spread under the cap |
| --- | --- | --- |
| Peak grid | 240.0 kW | 143.7 kW |
| Over the 180 kW cap | 60.0 kW | 0 kW |
| Plug energy | 533.3 kWh | 533.3 kWh |
| Unmet energy | 0 | 0 |
| Cars ready by 07:00 | 20 / 20 | 20 / 20 |
| Example EV bill | ₹4,267 | ₹2,859 |
| Example EV carbon | 384.0 kg | 287.5 kg |
| Solar used by EVs | 0 kWh | 0 kWh |

Peak cut is 96.3 kW, about 40%. The example bill drops about ₹1,408. The example carbon drops about 96 kg.

Those last two move only because the example night rate and the example night carbon are lower. Change the price table and the bill result changes. The peak result does not depend on the price table.

## What the outputs are not

The cars still take 533.3 kWh. This does not conserve battery energy. It moves when that energy is drawn so the site stays under 180 kW.

Solar used is zero in both columns. A renewable claim needs a daytime arrival or a battery, which this estimate does not have.

Do not quote 40%, ₹1,408, or 96 kg as a field result. They are the output of this toy, regenerated by the script.
